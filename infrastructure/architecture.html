OffTopicQuestion
Intentionally removed — topic policy evaluates the raw question in isolation (without document context), causing false positives. E.g. "Who is Sandra?" was blocked when Sandra was a character in the uploaded story.
✦ Contextual grounding (0.7 threshold) handles off-topic answers on the output side — no separate denied-topic policy needed.
Contextual Grounding (RAG check)
GROUNDING threshold: 0.7
Blocks responses not supported by the retrieved document chunks — prevents hallucinations
RELEVANCE threshold: 0.7
Blocks responses that don't address the user's query from the context provided
Blocked Input: "Your question contains content that cannot be processed. Please rephrase and try again."
Blocked Output: "The response was blocked because it did not meet content or grounding requirements."

You are a document assistant. Answer strictly from the supplied context. If the answer is not present in the context, say: Not found in document. Context: [chunk 1 text] --- [chunk 2 text] ...up to 5 chunks (KNN top-k=5) Question: {user question}

AWS Services Summary
Service Resource / Config Role in Architecture Key Config
Amazon Cognito		 User Pool SRP authentication, issues JWT id/access/refresh tokens Amplify v6 SDK; Cognito Authorizer on API Gateway
API Gateway		 REST API (HTTP) Routes upload, register, list-documents endpoints; validates JWT on every request Cognito Authorizer; Lambda proxy integrations
Amazon S3		 talktodoc-uploads + static-assets bucket Stores uploaded documents; triggers ingestion; hosts React SPA Pre-signed PUT URLs; ObjectCreated event → IngestDocumentFunction
AWS Lambda		 6 functions GeneratePresignedUrl, RegisterDocument, IngestDocument, ListDocuments, QueryDocumentStream (standard), QueryDocumentStreamReranked Ingest: 300s / 2048 MB; QueryStream: RESPONSE_STREAM Function URL; QueryStreamReranked: RESPONSE_STREAM · 120s timeout
Amazon DynamoDB		 Documents table Stores document metadata; tracks ingestion status; enforces ownership in query path GSI on userId; fields: documentId, userId, status, fileName, size
Amazon Bedrock		 Titan Embed Text v2 + Claude Haiku 4.5 + Claude Sonnet 4.6 Generates 1024-dim embeddings; Haiku scores rerank candidates (0–10, 20 parallel calls); Sonnet streams final answer tokens Titan: 1 call/chunk at ingest + 1 at query; Haiku: 20 parallel scoring calls (reranked mode); Sonnet 4.6: streaming; Guardrail applied on every Sonnet call
Bedrock Guardrails		 BedrockGuardrail (CloudFormation managed) Enforces content safety, topic restriction, and RAG grounding on every Bedrock call Content filters (HATE/VIOLENCE/SEXUAL/INSULTS/MISCONDUCT/PROMPT_ATTACK) · Denied topic: off-document questions · Contextual grounding ≥0.7 + relevance ≥0.7
OpenSearch Serverless		 VECTORSEARCH collection — talktodoc-index Stores and searches 1024-dim chunk embeddings; KNN retrieval filtered by documentId; terms query for neighbour expansion HNSW / cosine; Standard: k=5; Reranked: k=20 → rerank → top 5 + ±1 neighbours; AllowFromPublic network policy; IAM data access for Lambda roles
Amazon CloudFront		 Distribution → S3 origin CDN for React SPA; HTTPS termination, edge caching S3 static-assets bucket origin
AWS IAM		 Lambda execution roles Least-privilege roles for each Lambda; OpenSearch data access policies Separate roles for Ingest + Query; Bedrock, S3, DynamoDB, OpenSearch permissions
